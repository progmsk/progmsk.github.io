# Московский клуб программистов

Исходный код сайта московского клуба программистов.

## Стили

- `assets/css/style.css` — сгенерированный CSS (Bootstrap 5.3.2 + тема).
  Не редактируйте его руками: он сжат, и правки в нём потеряются.
- `assets/css/site.css` — свои стили сайта. Правьте только его:
  файл подключается после `style.css` и может переопределять фреймворк.

SCSS в репозитории больше нет: он требовал локальную сборку dart-sass,
а автокомпиляция на GitHub Pages невозможна — её сборщик (jekyll-sass-converter 1.x,
libsass) не умеет ни резолвить наши импорты, ни собирать Bootstrap 5.3.
Если однажды понадобится сильно поменять оформление, исходники Bootstrap/темы
можно достать из истории git (коммиты до 25.11.2026) и пересобрать CSS локально.
