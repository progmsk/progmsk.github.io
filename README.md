# Московский клуб программистов

Исходный код сайта московского клуба программистов.

## Стили

- `assets/css/style.css` — сгенерированный CSS (Bootstrap 5.3.2 + тема).
  Не редактируйте его руками: он сжат, и правки в нём потеряются.
- `assets/css/site.css` — свои стили сайта. Правьте только его:
  файл подключается после `style.css` и может переопределять фреймворк.

SCSS в репозитории больше нет (и не сохранился в истории — история сжата
до одного коммита). Автокомпиляция SCSS на GitHub Pages всё равно
невозможна: её сборщик (jekyll-sass-converter 1.x, libsass) не умеет ни
резолвить наши импорты, ни собирать Bootstrap 5.3. Если однажды понадобится
глобальный редизайн: исходники Bootstrap — с getbootstrap.com, тема —
Webestica Social; собрать CSS dart-sass'ом и закоммитить результат.
